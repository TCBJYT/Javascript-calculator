Simple calculator:

  -Basic calculator UI using JavaScript Eventlistener.
  -A user interface with buttons for digits (0-9) and basic operations (addition, subtraction, multiplication, division).
  -A display area to show the input and result.
  -Event listeners to handle button clicks and perform the calculations.
  -Clear and equals buttons.
  -Used Tailwind CSS framework for styling to make the development faster and ensure responsiveness.
